# Histórico do projeto

## 1.2 — Preparação de ambiente e versionamento

- Detecção de JDK 17/21 no script Windows e compilação Gradle 8.7.
- Diagnóstico de falhas de build em `logs/gradle-build.log`.
- Código testado no Fire Stick Lite com 6/6 testes funcionais aprovados.
- Organização em repositório Git, documentação e CI Android.

## 1.1 — Diagnóstico de build

- Script registra a saída completa do Gradle e valida ferramentas antes da compilação.

## 1.0 — Launcher minimalista

- Layout nativo escuro com Netflix e Claro TV em destaque.
- Navegação por D-pad e grade de aplicativos.
- Instalação ADB independente do launcher original da Amazon.

> O versionamento Git começa neste pacote consolidado. Entradas históricas descrevem as versões anteriores, não representam commits anteriores existentes.
